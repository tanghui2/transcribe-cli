# 六张方向卡

> 三套逻辑各出两个候选。挑最强、彼此最不一样的三张做完整版。
> 输出格式统一：**单文件 HTML，1440×900 桌面窗口**，含 3 个界面状态（工作台 / 结果查看器 / 设置）。

---

## 卡 1 · 最佳设计师｜**Michael Bierut**（大胆）

- **逻辑与来源**：Michael Bierut。做工具型软件的品牌与界面（Pentagram 为 IBM / Penguin / 耐克做的界面语言）。启用他的思维：工具的界面应该像机器的一部分——每个元素都有功能，没有装饰。
- **借的是什么**：**把「状态」做成界面的主角**——不做多色标签，而是一条贯穿顶部的状态带，用形状和位置表达"现在发生到哪一步"。量出来的数：Buzz 89% 是浅底、accent 只占约 1%。我借它的反面：**accent 面积要够大到能当状态指示器用**，而不是一个小图标。
- **不借的、自己长的**：不借 Pentagram 那种大 corporate sans + 大留白营销页语言。这次是**操作密集型工具**，界面上永远有内容，不留大片空白呼吸区。
- **主角素材**：**真实波形**（从音频文件按段落响度程序化生成，不是装饰插画）+ 真实转写文字。
- **骨架**：**顶部状态带（贯穿全宽的一条，处理阶段一目了然）＋ 下方左右分栏**（左：文件与参数；右：结果）。状态带同时是进度条和阶段导航。
- **胆量花在哪**：整条顶部状态带做成实心色块，颜色随阶段推进而变——从冷灰到暖橙到完成态的绿。它不是一条细进度线，是这个软件的脸。
- **form 来自内容的哪里**：转写是一条**流水线**（解码 → 识别 → 润色 → 翻译 → 导出），状态带就是这条流水线本身。
- **气质**：锐利、确定、机器感。

## 卡 2 · 最佳设计师｜**杉浦康平**（克制、东亚）

- **逻辑与来源**：杉浦康平。做书籍装帧与信息设计（《时装设计》的网格系统）。启用他的思维：信息量大的东西要靠**网格和留白节奏**分层，而不是靠装饰和卡片。
- **借的是什么**：**严格的栏格 + 字号的层级对比**，内容按栏格落位，不靠卡片框起来。杉浦的网格是"信息容器"——横竖分割线本身就是版式元素，不额外加边框。
- **不借的、自己长的**：不借他那套和纸底 + 靛蓝的东方美学外观（那是他的表达层）。这次的颜色从**工具的属性**里来：屏幕、波形、时间轴。
- **主角素材**：**等宽字体的双栏字幕对照**（中文在左，英文在右，时间轴在中间）——这个"中间是时间"的排布本身就是字幕这个题材的形状。
- **骨架**：**中央时间轴为骨**。左右分列原文与译文，中缝是时间刻度和播放头。所有功能（摘要、导出、参数）收纳进上方与底部的横栏。
- **胆量花在哪**：**中缝那条时间轴做成界面的主结构**，不是一条细线，而是一列有刻度的宽栏，当前播放位置用一个实心块压在上面。
- **form 来自内容的哪里**：字幕的本质就是**两段文字被一条时间锁住**，这个界面把它做成物理结构。
- **气质**：安静、精密、有书卷气。

## 卡 3 · 现实参照｜**Buzz**（开源本地转写工具，MIT）

- **出处**：github.com/chidiwilliams/buzz · 参考板 `refs/buzz-ui-board.jpg`（4 张官方截图）
- **借的是什么**：**"任务队列 + 双击进查看器"的两段式工作流**。Buzz 的机制很好：主窗口只管排队（文件名 / 模型 / 任务 / 状态四列表），转写结果在独立窗口里看，不挤在一屏。
  - 量出来的数：Buzz 主窗口 936×666，四列表格占满主体，accent 橙只出现在"Run"按钮边框上（占比 <1%）
  - 借的是**表格列的信息密度**（文件名列最宽，状态列最窄）和**双击进入查看器**的层级关系
- **不借的、自己长的**：**不借它 89% 的浅灰白 + 纯黑字 + 1% 橙色的朴素**。这次要给它一套自己的颜色与密度逻辑。同时不借它把模型/任务/语言全塞进一个弹窗的做法——弹窗一次只做一件事。
- **主角素材**：真实转写文本（`out/开学典礼.srt`）、真实中文纪要（`out/开学典礼.summary.md`）、真实双语对照（`out/开学典礼.English.srt`）
- **骨架**：**左侧固定任务列表 + 右侧结果工作区**（不是弹窗进查看器，是常驻右栏 + 可全屏展开）。
- **胆量花在哪**：把**摘要和字幕做成两个可切换的视图**，共用同一份时间轴——切换时时间位置不丢。
- **form 来自内容的哪里**：这个工具的核心产出不是"一段文字"，而是**同一段内容的三种形态**（原文 / 纪要 / 译文），所以视图切换而不是页面跳转。
- **气质**：功能主义，密度高，接近专业软件。

## 卡 4 · 现实参照｜**MacWhisper**（€65 一次性买断）

- **出处**：macwhisper.com · 参考板 `refs/board-2.jpg`
- **借的是什么**：**首屏即产品正在工作的样子**，不是一个介绍版面。MacWhisper 的官网直接展示应用窗口截图而不是渲染一张宣传图。
  - 借的是**"把真实界面当主视觉"**这个决定，和 macOS 应用窗口的比例（16:10 圆角、标题栏居中）
- **不借的、自己长的**：不借它官网那套"大字压产品图"的营销页表达，也不借 macOS 拟物阴影（我们要跨三个平台）。窗口外壳借**结构**（标题栏 + 工具栏 + 内容区 + 状态栏四段），不借**材质**。
- **主角素材**：**本产品自己的界面截图**（三个方向的界面本身就是 UI 素材），加上真实转写结果
- **骨架**：**标准桌面应用四段式**：标题栏（文件名 + 状态）／工具栏（主操作）／内容区（结果）／状态栏（模型 + 设备 + 倍速）。功能全部通过工具栏和设置面板暴露，不藏进弹窗迷宫。
- **胆量花在哪**：**状态栏做成一条真实的数据读数条**——把「large-v3 · cuda float16 · 6.4x 实时 · 显存 15.2/16GB」这种底层状态直接露出来。普通用户看得懂"更快"，专业用户看得懂全部。
- **form 来自内容的哪里**：这个工具的用户是拿着它干活的，**底层状态就是产品的一部分**（本地推理、显存、倍速），藏起来等于放弃信任。
- **气质**：精致、克制、接近原生专业软件。

## 卡 5 · 秒数轮盘｜**电影感声波可视化 Cinematic Sound-Viz Dark**（web 第 8 条，S=8）

- **样张**：`assets/style-specimens/web/08-cinematic-sound-viz.jpg`
- **借的是什么**：**波形作为真实数据图像贯穿界面**。样张里波形不是插画，是音频本身的可视化——柱子高度对应响度。我借这个机制，并且让它**承担功能**：波形上的段落块就是转写出来的字幕段，点哪块跳哪。
- **不借的、自己长的**：不借样张的纯黑底 + 蓝紫渐变（那是它的表情层）。也不借"巨标题压波形"——那是营销页做法，桌面工具不需要。这次波形**在浅底上、用一个单色**。
- **主角素材**：**程序化生成的真实波形**（按段落响度算出柱阵）+ 波形上的字幕段块。
- **骨架**：**波形为骨的全宽横栏**（顶部 1/3 高度），下面是文本区。波形不只是装饰，它就是导航条。
- **胆量花在哪**：波形占的面积比 Buzz 整张主界面都大——**波形是这个软件的第一主角**，因为它把"哪一段是什么"一次性说清楚。
- **form 来自内容的哪里**：转写这件事的输入是声音，输出是带时间戳的文字。**波形是那段时间的形状**，界面把它放在最显眼处是对的。
- **气质**：有电影感、沉浸、安静。

## 卡 6 · 秒数轮盘｜**田中一光几何平面构成**（east 第 9 条，S=8 → 8%12+1=9）

- **样张**：`assets/style-specimens/east/`（田中一光几何平面）
- **借的是什么**：**用几何色块与分割线组织信息，而不是用卡片和圆角**。田中的构成里，色块的大小关系就是信息层级：主色块最大、次级次之、点缀最小。这次让**色块的面积比例直接对应功能权重**（转写区最大、设置最小）。
- **不借的、自己长的**：不借他作品里那些具体的红蓝黄几何形状（那是他的表达层）。颜色从工具题材来：波形、时间轴、字幕状态。
- **主角素材**：**几何分割的版面本身** + 真实转写文字填在色块里。
- **骨架**：**非对称分割的主工作区**——大块放当前转写结果，窄条放参数（竖排收在右侧），底部一条放进度与倍速。不用卡片，用分割线。
- **胆量花在哪**：**完全不用圆角卡片**，所有区域靠直线分割和色块面积区分。
- **form 来自内容的哪里**：转写输出有明确的**三档优先级**（正文 / 译文 / 时间戳），这个权重关系用面积比表达最直接。
- **气质**：硬朗、平面、几何秩序。

## 挑选结论

| 卡 | 逻辑 | 判断 |
|---|---|---|
| 1 · Bierut | 最佳设计师（大胆） | **入选**。状态带做主结构，机制清晰、有辨识度 |
| 2 · 杉浦康平 | 最佳设计师（克制） | **入选**。中央时间轴的骨架与字幕题材咬合得最紧 |
| 3 · Buzz | 现实参照 | **入选**。工作流最成熟，双栏视图切换的机制实用 |
| 4 · MacWhisper | 现实参照 | 备选。与卡 1 的"状态"主题重叠，骨架不够独特 |
| 5 · 声波可视化 | 轮盘 | 备选。波形做主角的机制好，但纯波形+文本两段较常规 |
| 6 · 田中一光 | 轮盘 | 备选。无卡片分割的骨架有趣，但与"功能齐全"的信息密度要求有冲突 |

**三张的骨架互不重复**：卡 1 顶部状态带＋左右分栏 / 卡 2 中央时间轴为骨 / 卡 3 左队列＋右工作区（视图切换）。
**气质有区分**：卡 1 锐利机器感（深色强调） / 卡 2 安静精密（浅色克制） / 卡 3 功能主义（中性高密度）。
